Política de Privacidad — Informe de Auditoría

Última actualización: 28/08/2026

Esta aplicación permite a auditores/técnicos generar informes de auditoría en PDF, a partir de fotos tomadas con la cámara del celular y texto que el propio usuario escribe, y compartir ese PDF usando la función nativa de "Compartir" del celular (por ejemplo para enviarlo por correo electrónico desde la app de correo que el usuario elija, con su propia cuenta).

Qué datos se usan

La aplicación utiliza las fotos que el usuario toma voluntariamente con la cámara del celular, junto con los datos del cliente y las descripciones/observaciones que el usuario escribe, para armar un PDF.

Almacenamiento

Las fotos y el PDF generado no quedan guardados de forma permanente en ningún servidor: se procesan en memoria únicamente durante el momento en que se genera el PDF y se descartan inmediatamente después de que la respuesta llega al celular del usuario.

Con quién se comparten los datos

La aplicación en sí no envía el PDF a nadie ni lo comparte con terceros: solo lo entrega al propio celular del usuario, que decide con qué aplicación compartirlo (correo, WhatsApp, etc.) y a quién enviárselo, usando sus propias cuentas. No se usan los datos con fines publicitarios.

Permisos utilizados

La aplicación solicita acceso a la cámara únicamente para permitir tomar las fotos del informe. No accede a otros datos del dispositivo.
