Esta aplicación permite a técnicos generar informes en PDF de instalaciones, a partir de fotos tomadas con la cámara del celular, y enviarlos por correo electrónico a los destinatarios que el propio usuario selecciona.

Qué datos se usan

La aplicación utiliza las fotos que el usuario toma o selecciona voluntariamente desde su celular, junto con los títulos y observaciones que el usuario escribe, para armar un PDF. Ese PDF se envía por correo electrónico a las direcciones que el propio usuario indica al momento del envío.

Almacenamiento

Las fotos y el PDF generado no quedan guardados de forma permanente en ningún servidor: se procesan en memoria únicamente durante el momento del envío del correo y se descartan inmediatamente después.

Con quién se comparten los datos

Los datos (fotos, títulos y observaciones) solo se envían, en forma de PDF adjunto, a los destinatarios de correo electrónico que el usuario elige explícitamente antes de enviar el informe. No se comparten con terceros ni se usan con fines publicitarios.

Permisos utilizados

La aplicación solicita acceso a la cámara únicamente para permitir tomar las fotos del informe. No accede a otros datos del dispositivo.
